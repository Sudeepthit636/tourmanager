**Tour Package Management System**

 *Overview:*
 The Tour Package Management application is designed to help users (administrators) efficiently manage the tour packages by providing a user-friendly interface for creating, viewing, updating and deleting the tour packages. It includes essential features such as secure user authentication, allowing users (customers) to sign up and log in to their accounts as well as profile management to update personal information. With in-built validation such as email validation, mandatory fields validation, validations for Maximum Tour Group Size and Price fields, the application ensures a seamless user experience while enhancing productivity and organization in both personal and professional settings.

**This apps **contain** the following features:**

For Administrator,
* Login 
* Logout
* Add Tour Packages
* View Tour Packages
* Update Tour Packages
* Delete Tour Packages

For Customer,
* SignUp 
* Login 
* Logout 
* Update Profile

-----

**Limitations**
* Registration for Administrator will be implemented via Single Sign On (SSO) which is Out of scope for this implementation

**How To Login as Administrator**
* Register user 
* Update role from 'customer' to 'admin' in MongoDB database manually
